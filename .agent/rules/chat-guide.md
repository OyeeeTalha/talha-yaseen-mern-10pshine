# Antigravity Project Rules

## 1. Interaction Style
- **Strict Brevity:** No introductions, no pleasantries, no "Here is the update."
- **No Chat Snippets:** Do not display code in the chat. Write all code directly to files.
- **No Summaries:** Never create summary files (.txt, .md) in the project directory.
- **Direct Execution:** Perform the task and confirm completion with a single sentence or status line.

## 2. Technical Standards
- **Physics Logic:** Ensure all antigravity calculations maintain sign-reversal consistency for vector fields.
- **Documentation:** Use LaTeX for physics formulas in code comments (e.g., $F_{ag} = -\nabla \Phi$).
- **Efficiency:** Minimize dependencies; prioritize raw performance over abstraction.

## 3. Constraint Checklist
- [ ] Zero verbose fluff.
- [ ] No code in chat UI.
- [ ] No summary/log files.
- [ ] LaTeX for formal math only.
